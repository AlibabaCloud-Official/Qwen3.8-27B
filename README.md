Welcome to the repository for **Qwen3.8-27B**—the latest native multimodal dense open-weight model released by Alibaba's Qwen team. Delivering top-tier performance for local hardware, Qwen3.8-27B excels at coding, agentic workflows, and office automation tasks.

---

## 🔥 Key Highlights

* **Native Multimodal Architecture**: Seamlessly integrates text and vision understanding.
* **Compact yet Powerful**: With only 27B parameters, it outperforms **Qwen3.7-Plus** overall and excels in real-world software engineering and office workflows.
* **Massive Context Window**:
  * **262K tokens** native context length.
  * Easily extendable up to **1M tokens** using YaRN.
* **Open & Builder-Friendly**: Released under the permissive **Apache 2.0** license.
